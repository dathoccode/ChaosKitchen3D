# Chaos Kitchen 3D

**Chaos Kitchen 3D** is a 3D cooking game developed with Unity, where players take on the role of a chef and prepare food by interacting with different kitchen objects.

The project focuses on cooking gameplay, object interactions, player movement, and modular game systems.

## 🎮 Game Overview

In Chaos Kitchen 3D, players navigate a kitchen, interact with counters and kitchen objects, and perform cooking-related actions. The game is designed to provide an engaging gameplay experience through interactive objects and interconnected kitchen mechanics.

## ✨ Features

- **3D Player Movement:** Control the player and navigate around the kitchen.
- **Kitchen Object Interaction:** Interact with counters and other kitchen objects.
- **Object Pickup and Placement:** Pick up and carry kitchen objects using an object-holding system.
- **Modular Interaction System:** Organize interaction logic into reusable components.
- **Physics-Based Collision:** Use Unity's physics system to handle movement and environmental obstacles.
- **Animation Integration:** Connect player movement and interactions with character animations.

## 🛠️ Technologies

- **Game Engine:** Unity
- **Programming Language:** C#
- **Physics:** Unity Physics
- **Version Control:** Git and GitHub

## 📁 Project Structure

The project follows Unity's standard project structure:

- `Assets/` – Game scripts, scenes, prefabs, materials, models, and other game assets.
- `Packages/` – Unity packages and project dependencies.
- `ProjectSettings/` – Unity project configuration and settings.

## 🚀 Getting Started

1. Clone or download this repository.
2. Open Unity Hub.
3. Select **Add Project from Disk** and choose the project directory.
4. Open the project using a compatible Unity version.
5. Open the main game scene and press **Play** to run the game.

> Note: The Unity version and required dependencies should match the project's configuration.
